# KnowledgeFlow AI

KnowledgeFlow AI is an AI-powered enterprise knowledge hub for managing
documents, meeting transcripts, decisions, action items, and project knowledge.

## Current MVP infrastructure

- Frontend: React
- Backend: Python
- API: Amazon API Gateway
- Compute: AWS Lambda
- Document storage: Amazon S3
- Structured database: Amazon RDS for PostgreSQL
- AI services: Amazon Bedrock
- Monitoring: Amazon CloudWatch

## Repository structure

- `backend/`: Python backend and AWS integrations
- `frontend/`: Web frontend
- `database/`: PostgreSQL schema
- `sample-files/`: Development sample documents
- `docs/`: Project documentation
